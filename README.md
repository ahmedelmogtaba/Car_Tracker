# Car_Tracker:

In-class project of the Computer Vision Part 2 course during AMMI master 2021.

### Project summary :

Make use of the pretrained "COCO-InstanceSegmentation/mask_rcnn_R_50_FPN_3x.yaml" model form detectron2 library to implement car traicking system.
